# バブルポップ音声ファイル

このディレクトリに `bubble_pop.mp3` を配置すると、カスタム音声が再生されます。

## 使用方法

1. 泡が弾けるような音声ファイル（MP3形式）を用意
2. ファイル名を `bubble_pop.mp3` にリネーム
3. このディレクトリに配置
4. `lib/services/sound_manager.dart` で `SoundManager.setUseCustomSound(true)` を呼び出す

## 推奨される音声ファイル

- **形式**: MP3
- **長さ**: 0.2〜0.5秒
- **音量**: 中程度
- **音の種類**: 泡が弾ける音、ポップ音、クリック音など

## 音声ファイルがない場合

音声ファイルがない場合は、システムの標準クリック音が自動的に使用されます。
